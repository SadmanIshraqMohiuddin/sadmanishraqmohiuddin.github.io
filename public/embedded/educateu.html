The Problem

A global education provider with no unified platform to match its ambitions

Planet Education Network (PEN) had built a credible portfolio of CPD and BSC-accredited compliance courses for the UK and global market. The product existed - learners were using it. But the underlying platform was not built for scale. Agent relationships were managed manually, admissions were paper-heavy, and there was no unified system connecting course delivery, student management, and institutional oversight.

The goal was to build a purpose-built LMS that could carry educateU from a course catalogue into a fully accredited, commercially scalable education platform - handling everything from agent commission management to degree admission journeys within a single RBAC-governed system.

🔗

No Unified Platform

Course delivery, agent management, admissions, and compliance tracking were siloed processes with no integrated system connecting them.

🏢

Agent Network Without Infrastructure

Education agents and sub-agents had no formal platform for application management, commission tracking, or communication with the institution.

🔐

No Access Control Architecture

With multiple user types (Admin, Agent, Student, Officer), a multi-level role-based access control system was needed from the ground up.

📝

Manual Admission Processes

Degree and diploma admission journeys were not systematised - no formal application lifecycle, document tracking, or decision workflow existed.

LEVEL 1 - CATEGORY
User Categories
Every registered user belongs to a category (Admin, Agent, Student, Officer). Category determines which modules are available by default.
LEVEL 2 - ROLE
Configurable Roles
Within each category, the Admin creates roles (e.g. HR Manager, Senior Agent). Roles group sets of module permissions that apply to assigned users.
LEVEL 3 - MODULE
Module Permissions
Roles are granted access to specific modules. Admin can assign any module within the registered category - or grant cross-category access as needed.
LEVEL 4 - USER
Individual Access
Each user inherits permissions from their assigned role. Temporary access overrides are time-limited and expire automatically without admin intervention.

UAT-03 User Mgmt / Sign In Functional Bug Username is case sensitive on login - should be case-insensitive for all users Critical High
UAT-05 User Mgmt / MFA Enhancement MFA re-authentication interval should be 15 minutes per session, not 24 hours - logout and re-login before interval should not re-prompt OTP High High
